# Ohidur Rahman | Portfolio

Personal e-portfolio (white and brown theme) built with plain HTML and CSS.

## Files
- `index.html`: the whole website
- `assets/profile.jpg`: profile picture
- `assets/intro.mp4`: add your introduction video here (optional). The video section shows it automatically once the file exists.
- `.nojekyll`: tells GitHub Pages to serve the files as they are

## Publish on GitHub Pages
1. Upload all files (including the `assets` folder) to your repository.
2. Go to Settings > Pages, choose the `main` branch and the root folder, then save.
